# 微信公众号注册与发布须知

## 账号类型

| 类型 | 资质 | 推送频率 | 自动发布API | 费用 |
|------|------|---------|-----------|------|
| 个人订阅号 | 身份证 | 每天1次 | ❌ 无发布API | 免费 |
| 企业订阅号(认证) | 营业执照 | 每天1次 | ✅ draft/free_publish | 300元/年 |
| 企业服务号(认证) | 营业执照 | 每月4次 | ✅ 完整API | 300元/年 |

- **个人订阅号无法通过 API 自动发布图文**，只支持素材管理（上传图片、草稿）
- Playwright 模拟浏览器登录后台发布存在风险：cookie 过期频繁（1-7天），可能触发风控
- 推荐方案：Hermes 生成内容 + 封面图 → 推送到微信 → 用户手动打开「微信公众平台」App 粘贴发布（约 30 秒/天）

## 注册流程（个人）

1. 访问 https://mp.weixin.qq.com
2. 选择「订阅号」类型
3. 使用未注册过公众号的微信号扫码绑定
4. 提交身份证信息
5. 设置公众号名称、头像、简介
6. 审核通常在 1-7 个工作日完成

## 命名注意事项

- 名称含「AI」「日报」「科技」等关键词可能触发人工审核
- 建议使用含蓄名称，如「监听站1379」「信号站」「见微」等
- 个人号一年可改一次名

## 头像设计要点

使用 Pillow 生成科技风圆形头像时：
- **主体**：同心雷达环 + 信号点 + 十字准线，简洁有力
- **文字**：放在左下角或右下角，用小字号避免遮挡主体
- **格式**：监听站·1379 用 · 连接，字体 NotoSansCJK-Regular 24px
- **背景**：半透明深色色块垫底，确保白底设备上可读
- **裁剪**：RGBA PNG 圆形裁剪，400×400 像素
- **避免**：扇形扫描区域会遮挡文字；文字居中会挤占设计空间
- **保存路径**：/root/.hermes/audio_cache/avatar_XXXX.png

## 发布流程（半自动）

```
Hermes 生成日报
  → 自动生成 1200×630 封面图
  → 渲染为公众号可粘贴格式
  → 推送至微信
  → 用户在「微信公众平台」App:
    ① 保存封面图到手机
    ② 新建图文 → 上传封面
    ③ 粘贴正文 → 发布
```

## API 限制

- access_token 2 小时过期，需定时刷新
- 个人订阅号 endpoints: 素材管理（draft/add 等），但没有 draft/free_publish
- 认证订阅号 endpoints: draft/add → draft/free_publish → 轮询发布结果
- IP 白名单需在后台配置
- 每日发布次数：订阅号 1 次，服务号 4 次/月
